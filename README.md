## 📚 Key Capabilities

- **Algorithmic Grade Averaging:** Computes arithmetic and weighted student grade metrics with numeric rounding.
- **Dynamic Student Matrix:** Interactive gradebook tables with inline cell validations and real-time total updates.
- **Conditional Color Telemetry:** Instantly flags passing marks (green), warnings (yellow), and remediation states (red).
- **Responsive Educational Dashboard:** Designed for teachers and students across desktop, tablet, and mobile views.
